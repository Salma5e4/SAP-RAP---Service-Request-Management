# SAP-RAP---Service-Request-Management


## Project Overview

This project is developed using SAP ABAP RESTful Application Programming Model (RAP).

## Technology Used

- SAP ABAP
- SAP RAP
- CDS Views
- Behavior Definition
- Behavior Pool
- Projection View
- Service Definition
- Service Binding
- Fiori Elements

## Project Objects

- ZSRM_REQUEST - Database Table
- ZI_SR_REQUEST - Interface CDS View
- ZBP_I_SR_REQUEST - Behavior Pool
- ZC_SR_REQUEST - Projection CDS View
- ZUI_SR_REQUEST - Service Definition

## Project Flow

Database Table  
↓  
Interface CDS View  
↓  
Behavior Definition  
↓  
Behavior Pool  
↓  
Projection CDS View  
↓  
Projection Behavior  
↓  
Service Definition  
↓  
Service Binding  
↓  
Fiori Preview
